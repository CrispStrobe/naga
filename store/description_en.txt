19 snake game modes in one app — retro classic to roguelike dungeon crawler

Full description:
Naga is the ultimate snake game — 19 distinct game modes in one app, from a faithful retro phone-era classic to a full roguelike dungeon crawler.

GAME MODES

Classic
- Classic: The original snake experience, authentic retro rules
- Arcade: Neon speed run
- Zen: No death, just vibes

Crossover
- Maze Hunter: Pac-Man meets Snake
- Trail: Tron-style light cycles
- Fangs: Breakout with a bite
- Venom: Bomb and blast

Action
- Pit: Last snake standing
- Swarm: Eat the invaders
- Rush: Endless auto-scroll

Legacy
- Snake II: Maze levels and wrap-around
- ASCII: Terminal text mode
- CGA: 4-color retro PC
- Nibbles: QBasic classic

Minigames
- Stampede: Animal race track
- Naga Dive: Underwater swim

Adventure
- Dungeon: Turn-based roguelike crawler — explore rooms, fight enemies, collect loot

Multiplayer
- Duel: Local 2-player, same device
- VS AI: Challenge AI opponents across 4 difficulty levels

FEATURES
- 19 distinct game modes, each with its own rules, look, and music
- Configurable grid size, wall behavior, lives, difficulty, and starting speed
- Power-ups: Speed, Shield, Magnet, Slow, Shrink
- Local high scores and 10 achievements
- D-pad and swipe controls
- Smooth, responsive touch controls with haptic feedback
- Works offline — no internet required after install
- No ads, no accounts, no data collection
- Runs on Android, iOS, and web

CONTROLS
- Swipe or use the on-screen D-pad to steer
- Tap to start or pause
- Simple, intuitive, and responsive
